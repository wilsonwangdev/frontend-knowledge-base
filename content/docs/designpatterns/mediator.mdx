---
title: Mediator
---

Mediator is a behavioral design pattern that lets you reduce chaotic dependencies between objects. The pattern restricts direct communication between objects, forcing them to collaborate only via a mediator object.

## Usage

```js
class Mediator {
  constructor() {
    this.colleagues = [];
  }

  addColleague(colleague) {
    this.colleagues.push(colleague);
  }

  send(message, sender) {
    this.colleagues.forEach((colleague) => {
      if (colleague !== sender) {
        colleague.receive(message);
      }
    });
  }
}

class Colleague {
  constructor(mediator) {
    this.mediator = mediator;
  }

  send(message) {
    this.mediator.send(message, this);
  }

  receive(message) {
    console.log(`Received: ${message}`);
  }
}

const mediator = new Mediator();
const colleague1 = new Colleague(mediator);
const colleague2 = new Colleague(mediator);

mediator.addColleague(colleague1);
mediator.addColleague(colleague2);

colleague1.send("Hello, colleague2!");
colleague2.send("Hi, colleague1!");
```
